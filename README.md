# Sanvik Home Care website

Static website for Sanvik Home Care (Sanvik LLC), Berkeley Heights, NJ. Hosted on Netlify.

| File | What it is |
|---|---|
| `index.html` | Home page (services, who we help, how it works, areas, FAQ, consultation form) |
| `careers.html` | Careers page with the caregiver application form |
| `privacy.html` | Privacy Policy |
| `robots.txt`, `sitemap.xml` | Helpers for search engines and AI assistants |

No build step: Netlify publishes the files in this folder as they are. Forms are handled by Netlify Forms.

Before going live, replace `G-XXXXXXXXXX` in `index.html`, `careers.html` and `privacy.html` with the Google Analytics Measurement ID.
